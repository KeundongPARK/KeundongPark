과제명
Junction Temp 모니터링 통한 Gpoly 두께 이상 선감지 후 Auto 이상 발의 최소화
    
작성자 박근동 · 2026.11.05 · 양산공정개발 및 파운드리 선단 Node 선행공정 품질 불량 개선

  
1. 문제 정의
    
    
  • Pain Point: Junction Temp 불량 시 Gpoly 두께 이상으로 Auto 이상 발의 (6개월간 3건)
    • 
    
  • 의사결정 질문: 후속 CMP·NSE Care 후 최종 두께는 Targeting했으나 OOS 근거로 출하금지 요청(양산QA)
    • 
    
  • 한계: 최종 NSE 후 두께 Targeting 시 수율 문제 없으나 QA 재가 불가로 Scrap 불가피

  
2. PoC 설계
    
    
  • 목표: Cold junction Temp 최근 5타점 연속 불량 시 자동 Hold → 엔지니어 비정규 계측 → Site 기준 limit-1 미이탈 시 Auto Release (이탈 시 Hold)
    • 
    
  • 적용 범위: S3 diffusion Gate Poly 전 PPID (All 제품)
    • 
    
  • 활용 데이터: EES의 FDC 실시간 Data (1sec)
    • 
    
  • 일정: 1~2주 데이터 수집·전처리, 프롬프트/모델 설계 · 3~4주 결과 검증, 현업 테스트 및 성과 측정
    • 
    
  • KPI: Wafer Loss 27매/6개월 → 0매

  
3. Claude 활용 및 비즈니스 가치
    
    
  • 프롬프트: 역할 · 맥락 · 과업 · 제약(추정 금지, 근거 명시) · 출력형식(HTML)
    • 
    
  • 산출물: 요약 3줄 → 핵심 지표 카드 → 차트 → 상세 표 → 권고 조치·확인란
    • 
    
  • 기대 효과: 27매/6개월 = 9.5억, 연간 19억 손실액 방지
    • 
    
  • 확산: 파일럿 확대 → 프롬프트·템플릿 자산화 → 정기 운영(양산공정 관리 편입)
